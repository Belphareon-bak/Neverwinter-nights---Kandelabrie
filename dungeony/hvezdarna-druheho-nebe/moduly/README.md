# Moduly Hvězdárny druhého nebe

Sem patří exporty `.mod` pro zkoušení Hvězdárny v Neverwinter Nights: Enhanced Edition. První sestavu popisuje závěr [námětu Hvězdárny](../README.md).

K přidanému modulu uveď odkaz na soubor, verzi hry, případné závislosti (`.hak`, `.tlk`) a způsob spuštění nebo importu. Při více sestavách pomůže verze v názvu, například `hvezdarna-0.1.mod`.
